# Руководство пользователя RouterAI Proxy

## Что это?

RouterAI Proxy — локальный прокси, который позволяет **точно выбрать конкретного провайдера (хост)** для любой модели RouterAI и жёстко зафиксировать его для OpenCode Desktop.

Как только вы выбрали провайдера — запросы идут **только** на него, с параметром `allow_fallbacks=false`. Прокси сам переключаться на других провайдеров не будет. Если цена выбранного провайдера вырастет — прокси заблокирует запросы и сообщит, что произошло.

## Быстрый старт

1. **Запустите прокси**
   ```bash
   python3 ~/bin/routerai-proxy/proxy.py
   ```
   На вопрос `Открыть страницу управления в браузере? (Y/n):` нажмите `Y` или `Enter`. Либо откройте вручную: http://127.0.0.1:5000

2. **Укажите API-ключ**
   Откройте `proxy_settings.json` (создаётся при первом запуске) и замените `api_key` на реальный ключ с https://routerai.ru. Перезапускать прокси не нужно.

3. **Загрузите список моделей**
   Нажмите кнопку **«Обновить модели»** в правом верхнем углу. Первая загрузка занимает ~6 секунд.

4. **Выберите провайдера**
   Найдите нужную модель, при необходимости отфильтруйте провайдеров по цене и нажмите **«Выбрать»** напротив подходящего хоста.

5. **Выгрузите конфиг OpenCode**
   В блоке **«Настройки»** нажмите **«Выгрузить конфиг OpenCode»** — в папке скрипта создастся `opencode.jsonc`. Скопируйте его:
   ```bash
   cp ~/bin/routerai-proxy/opencode.jsonc ~/.config/opencode/opencode.jsonc
   ```

6. **Работайте в OpenCode Desktop**
   Откройте чат и пишите сообщения — все запросы пойдут через выбранного провайдера.

## Как работает фильтрация?

### Поля фильтра
Введите значения в любое поле — фильтрация происходит мгновенно:

| Поле | Что делает |
|------|-----------|
| **Минимум Контекста** | Оставляет провайдеров с окном контекста не меньше указанного (в тысячах токенов) |
| **Макс. цена Входа** | Оставляет провайдеров дешевле указанной цены за 1 млн входных токенов |
| **Макс. цена Выхода** | Оставляет провайдеров дешевле указанной цены за 1 млн выходных токенов |
| **Макс. цена Кэша** | Оставляет провайдеров дешевле указанной цены за 1 млн кэш-токенов |

Фильтры сохраняются автоматически и восстанавливаются при следующем открытии страницы.

### Пример
Ищете провайдера для DeepSeek V4 Flash с контекстом от 1 млн и ценой выхода до 25 ₽:
1. **Минимум Контекста** → `1024`
2. **Макс. цена Выхода** → `25`
3. В таблице останутся только подходящие хосты

### «Показать остальных (N)»
Если под фильтр попали лишь некоторые провайдеры модели — внизу блока модели появится кнопка:
```
▶ Показать остальных (15)
```
Нажмите — откроются все скрытые фильтром провайдеры (полупрозрачные, чтобы отличать неподходящие). Повторное нажатие сворачивает их обратно.

## Дополнительные тарифы провайдеров

Под некоторыми провайдерами появляются **жёлтые строки** — это альтернативные тарифы из `variable_pricings`:

| Тип тарифа | Как отображается | Пример |
|-----------|------------------|--------|
| По времени (`time-of-day`) | Часовой диапазон в **московском времени** (UTC+3) | `03:00–17:00 МСК` |
| По объёму (`prompt-threshold`) | Порог контекста | `От 32K` |

**Как читать:** первая строка — базовый тариф, следующие жёлтые — альтернативные условия. Например, у Alibaba ночью (по МСК) цены вдвое выше дневных.

Такие строки привязаны к конкретному провайдеру и скрываются/показываются вместе с ним при фильтрации.

## Колонка «Дополнительно»

Всё, что не вошло в отдельные колонки (Вход / Выход / Кэш чтения / Кэш записи), выводится здесь с русским названием и правильной единицей:

```
Входящие изображения: 0.01 ₽/1К токенов
Входящие аудио: 33.11 ₽/1М токенов
Размышления: 44.15 ₽/1М токенов
Веб-поиск: 1545.27 ₽/1К вызовов
Кэш: аудио: 3.31 ₽/1М токенов
Запрос: 4.42 ₽/1 запрос
```

**Запрос** — цена за вызов целиком (для моделей, которые считаются не по токенам, а по операциям: генерация видео, клипов, изображений). Пример — Google Lyria 3 Clip Preview: `4.42 ₽` за клип.

Если RouterAI добавит новый тип цены, он не потеряется: неизвестный ключ выведется с техническим именем и реальной единицей из `pricing_units`, без попыток угадать масштаб.

В блоке профиля тот же список отображается в одну строку на позицию.

## Сравнение затрат

Отметьте **«сравнить»** у нужных провайдеров и нажмите **«Сравнение затрат»**. Таблица показывает стоимость одного и того же сценария у каждого провайдера, с разбивкой по четырём позициям.

### Сценарии

Четыре готовых сценария плюс свой:

| Сценарий | Вход | Выход | Рассуждения | Кэш-чтение | Что проверяет |
|---|---|---|---|---|---|
| Простой диалог | 1 000 | 500 | 0 | 0 | базовые цены |
| Анализ большого документа | 20 000 | 2 000 | 2 000 | 0 | дорогой вход |
| Работа с базой знаний | 2 000 | 800 | 400 | 50 000 | скидка за кэш |
| Агентная разработка | 40 000 | 15 000 | 15 000 | 600 000 | выход + рассуждения + кэш сразу |
| Свой сценарий | свои числа | | | | |

Свой сценарий обведён рамкой и подсвечен насыщеннее пресетов. Лучшая цена и вторая по величине залиты цветом; при ничьей отмечаются все ячейки с такой ценой.

### Как считается стоимость

Каждая позиция — количество токенов из сценария × цена этой позиции:

| Позиция | Формула |
|---|---|
| Вход | токены входа × цена входа |
| Выход | токены выхода × цена выхода |
| Рассуждения | × цена рассуждений, если провайдер её указывает |
| Кэш чтение | × цена кэша |
| **Итого** | сумма четырёх позиций |

Цена **записи** кэша в расчёт не входит: калькулятор считает чтение уже закэшированного контекста.

### Когда позиция не поддерживается

У RouterAI это разные вещи, и калькулятор их различает:

| Состояние | Как считается |
|---|---|
| Цена есть | по ней |
| Цена **0 ₽** при поддержке — операция бесплатна | **0 ₽** |
| Ключа цены нет — операция **не поддерживается** | см. ниже |

- **Рассуждения не поддерживаются** — берётся цена выхода: провайдер не выделяет рассуждения и считает их обычными выходными токенами.
- **Рассуждения бесплатны** — 0 ₽, а не цена выхода.
- **Кэш не поддерживается** — берётся цена входа: закэшировать нечем, токены уйдут как обычный вход.
- **Кэш бесплатен** — 0 ₽, а не цена входа.

В колонках каталога неподдерживаемая позиция показывается прочерком `—` с подсказью, а не нулём: нуль там был бы неотличим от бесплатной операции.

### «Не сравнимо»

Провайдеры с ценой **за запрос** (видео, клипы, изображения) не считаются по токенам — для них калькулятор выводит `не сравнимо`.

### Предупреждения

Под ценой появляются плашки, если сценарий не влезает в провайдера:

- `⚠ контекст 640K > 262K` — входные токены вместе с кэшем больше окна контекста
- `⚠ выход 30K > 32K` — выходные токены вместе с рассуждениями больше лимита выхода

Стоимость при этом считается как есть, по указанным в сценарии токенам.

## Выбор провайдера

Нажмите **«Выбрать»** напротив нужного хоста. Страница не перезагружается — блок профиля вверху обновляется мгновенно.

При выборе:
- Запоминаются модель и провайдер
- **Фиксируются текущие цены** — они становятся эталоном для монитора
- Если была блокировка — она **снимается автоматически** (вы явно приняли новые цены)

## Блокировка при изменении цен

Фоновый монитор проверяет цены выбранного провайдера каждые `check_interval_sec` секунд (по умолчанию 10 минут).

Если цена выросла — в блоке профиля появляется сообщение:
```
[ЗАПРОСЫ ЗАБЛОКИРОВАНЫ]
ЦЕНА ВЫРОСЛА! Вх: 0.28→0.56₽; Вых: 1.11→2.22₽
Выберите модель ниже, чтобы применить новые цены и снять блокировку.
```

OpenCode Desktop при попытке отправить запрос получит ошибку с той же причиной и ссылкой на панель:
```
Запросы заблокированы прокси! Причина: ЦЕНА ВЫРОСЛА! Вх: 0.28→0.56₽ ...
   → выберите другого провайдера [Открыть панель выбора](http://127.0.0.1:5000/)
```

### Как снять блокировку
1. Нажмите **«Обновить модели»**
2. Нажмите **«Выбрать»** напротив любого провайдера (можно того же)

При выборе цены перефиксируются по текущим значениям, и работа возобновится. Перезапускать OpenCode или прокси не нужно — просто отправьте сообщение повторно.

### Авто-открытие панели при блокировке
В панели фильтров, под чекбоксом **«Логирование в файл»**, есть переключатель:
```
☐ Авто-открытие панели при блокировке
```
- **Включено** — как только OpenCode наткнётся на блокировку по цене, на компьютере автоматически откроется вкладка `http://127.0.0.1:5000/` с панелью управления
- **Выключено** (по умолчанию) — нужно открыть панель вручную

Настройка хранится в конфиге (`auto_open_on_block`) и применяется сразу. В логе фиксируется:
```
[Прокси] Авто-открытие: панель управления открыта в браузере
```

## Логирование и авто-открытие

Блок **«Настройки»** (справа от профиля):

```
Настройки
☑ Включить запись в proxy.log
☐ Авто-открытие панели при блокировке
   ─────────────────────────────
[ Выгрузить конфиг OpenCode ]
```

| Элемент | Действие |
|---------|----------|
| **Включить запись в proxy.log** | писать все события (запросы, прокси, каталог) в `proxy.log` |
| **Авто-открытие панели при блокировке** | открывать вкладку с панелью управления при блокировке по цене |
| **Выгрузить конфиг OpenCode** | создать `opencode.jsonc` в папке скрипта |

Чекбоксы сохраняются в `proxy_settings.json` (`logging_enabled`, `auto_open_on_block`) и применяются **без перезагрузки** страницы и сервера.

## Конфиг для OpenCode

Кнопка **«Выгрузить конфиг OpenCode»** создаёт в папке скрипта файл `opencode.jsonc` с настройками провайдера:

```json
{
  "provider": {
    "custom": {
      "name": "RouterAI",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "http://127.0.0.1:5000/v1",
        "apiKey": "local-auth-not-needed"
      },
      "models": {
        "routerai/proxy-model": {
          "name": "RouterAI Контролируемая Модель",
          "limit": { "context": 1048576, "output": 131000 }
        }
      }
    }
  },
  "compaction": { "auto": true, "reserved": 15000 }
}
```

### Как использовать
```bash
cp ~/bin/routerai-proxy/opencode.jsonc ~/.config/opencode/opencode.jsonc
```

### Обновление уже настроенного конфига
Если в вашем `opencode.jsonc` есть другие провайдеры и настройки — не пересоздавайте файл. В блоке **«Настройки»**:

1. ☑ **Разрешить изменение существующего конфига**
2. Укажите **путь к конфигу** (например `~/.config/opencode/opencode.jsonc`)

Дальше ничего нажимать не нужно. При каждом нажатии **«Выбрать»** конфиг обновляется сам, результат виден под полем пути.

Прокси точечно поменяет только порт в `baseURL` и `limit.context` / `limit.output` внутри блока `routerai/proxy-model`. Комментарии, оформление и все остальные настройки (включая других провайдеров) остаются нетронутыми — файл правится как текст, без JSON-парсинга.

Перед первой правкой создаётся бэкап `opencode.jsonc.bak`. Если файла по указанному пути нет — обновление не произойдёт, и об этом будет написано в той же строке.

Поле пути активно только при включённом чекбоксе: без явного разрешения правка невозможна.

### Про `limit`
Это **не** ограничение провайдера, а установка для OpenCode:
- `context` — сколько токенов истории диалога он считает доступными
- `output` — сколько резервирует под ответ

Кнопка берёт `context` из `context_length` **выбранного вами провайдера**, поскольку за прокси стоит одна виртуальная модель, а реальные провайдеры имеют разные лимиты (262K / 400K / 1M). Если не обновить конфиг при смене провайдера — OpenCode будет считать лимит неверным и сожмёт историю не вовремя.

### Про `compaction`
| Параметр | Что делает |
|----------|-----------|
| `auto: true` | автоматически сжимает историю диалога при приближении к лимиту |
| `reserved: 15000` | оставляет 15 000 токенов под ответ модели |

В нашем случае необходим: провайдер меняется на лету, у каждого свой лимит, и длинный диалог неизбежно упрётся в потолок. Без `auto` провайдер просто вернёт ошибку переполнения. С ним — OpenCode сам сожмёт историю и чат продолжит работу.

## Кэширование моделей

Список моделей хранится в файле `catalog_cache.json`:
- **Открытие страницы** — модели появляются мгновенно из кэша (без обращения к RouterAI)
- **Кнопка «Обновить модели»** — загружает свежие данные из API и перезаписывает кэш
- Время последнего обновления показано над кнопкой: `Данные моделей обновлены: 10.10.2026 12:15`

Если RouterAI недоступен — на странице останутся модели из кэша, а не пустой экран.

## Часто задаваемые вопросы

### Как узнать, какой провайдер выбран?
В блоке **«Зафиксированный рабочий профиль в OpenCode»** вверху страницы.

### Можно ли выбрать другого провайдера?
Да. Нажмите **«Выбрать»** напротив другого хоста — выбор обновится мгновенно без перезагрузки страницы.

### Нужного провайдера нет в списке — что делать?
1. Проверьте фильтры — возможно, провайдер отсечён по цене или контексту
2. Нажмите **«Показать остальных (N)»** — он мог быть скрыт
3. Нажмите **«Обновить модели»** — обновите каталог из API
4. Не помогло — провайдера действительно нет в RouterAI для этой модели

### Дата обновления не меняется после нажатия «Обновить модели»
Нажмите `Ctrl+F5` (жёсткая перезагрузка) — браузер мог закэшировать старый ответ. API отвечает заголовком `Cache-Control: no-store`, но кэш страницы может мешать.

### Модели не загрузились
Посмотрите `proxy.log` — там видно, какие модели не отдали данные и почему (таймаут/ошибка сети):
```
[Каталог] Ошибка загрузки endpoints для model-id: timeout
```

### Как изменить API-ключ?
1. Откройте `proxy_settings.json`
2. Измените `api_key`
3. Перезапускать прокси не нужно — параметр читается при каждом запросе

**Можно не хранить ключ в файле.** Задайте переменную окружения и укажите ссылку на неё:

```json
"api_key": "{env:ИМЯ_ПЕРЕМЕННОЙ}"
```

Переменная должна быть доступна процессу, из которого запущен прокси. Если её не окажется (или имя будет написано с ошибкой), прокси сообщит об этом с именем переменной — предупреждением при старте и в ответе на запрос.

### Файла `proxy_settings.json` нет
Он создаётся при **первом запуске** `proxy.py`. Сначала запустите скрипт, потом редактируйте настройки.

### Порт 5000 занят другим приложением
Укажите свой порт в `proxy_settings.json`:
```json
{ "port": 5555 }
```
и перезапустите прокси. Панель переедет на `http://127.0.0.1:5555`, а кнопка **«Выгрузить конфиг OpenCode»** сама подставит новый порт в `baseURL` — переписывать конфиг вручную не нужно.

### Не удалось занять порт
Скрипт сообщит об этом и подскажет причину. Освободить порт:
```bash
# Linux
lsof -i :5000
kill <PID>

# Windows
netstat -ano | findstr :5000
taskkill /F /PID <PID>
```

### Как перенести конфиг в OpenCode?
```bash
cp ~/bin/routerai-proxy/opencode.jsonc ~/.config/opencode/opencode.jsonc
```
Нажмите кнопку выгрузки заново после смены провайдера — `limit.context` подтянется актуальный.

### Нужно ли менять `compaction` вручную?
Нет, оставьте `auto: true` и `reserved: 15000`. Подробнее — в разделе «Конфиг для OpenCode» выше.

### Безопасно ли обновлять мой существующий конфиг OpenCode?
Да. Прокси правит файл **как текст** и меняет только два места: порт в `baseURL` и `limit.context` / `limit.output` внутри блока `routerai/proxy-model`. Комментарии, отступы, другие провайдеры и все остальные настройки не затрагиваются.

Дополнительные гарантии:
- правка выключена по умолчанию — нужно явно включить чекбокс и указать путь
- перед первой записью создаётся бэкап `opencode.jsonc.bak`
- если ключи не найдены или файла нет — файл не изменяется

### Обновление конфига не сработало
Смотрите сообщение под кнопкой:
- **«Замена не разрешена»** — включите чекбокс «Разрешить изменение существующего конфига»
- **«Путь не указан»** / **«Файл не найден»** — проверьте путь (поддерживается `~`)
- **«Ключи не найдены»** — в файле нет `routerai/proxy-model`; нажмите «Выгрузить конфиг OpenCode»

### Почему OpenCode Desktop не подключается?
1. Убедитесь, что прокси запущен
2. Проверьте `baseURL` в настройках провайдера: `http://127.0.0.1:<port>/v1`, где `<port>` — значение из `proxy_settings.json` (по умолчанию `5000`)
3. Проверьте, что ID модели — `routerai/proxy-model`
4. Проверьте, что в блоке профиля выбран провайдер (не сообщение «Модель не выбрана»)
5. Посмотрите `proxy.log` — есть ли строка `[Запрос] POST /v1/chat/completions`. Если её нет — OpenCode шлёт запрос не на тот адрес

### Порт 5000 занят
Скрипт снимает старые экземпляры автоматически при старте. Если порт занят другим приложением — укажите свой в `proxy_settings.json`:
```json
{ "port": 5555 }
```
Панель переедет на `http://127.0.0.1:5555`, а кнопка **«Выгрузить конфиг OpenCode»** сама подставит новый порт в `baseURL`.
